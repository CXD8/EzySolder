# EzySolder
A universal solder feeder

A compact, low-cost DIY solder wire feeder powered by an N20 DC gearmotor.

## Features
- N20 geared DC motor
- Ergonomic lightweight 3D-printable design
- Simple push-button operation
- Easy setup

## How It Works

1. Solder wire is pulled from a spool.
2. The N20 motor drives a teethed roller.
3. An idler bearing holds the solder wire against the roller.
4. Pressing the button advances the solder wire.
5. Releasing the button stops the motor.

## Assembly

1. Print the housing and drive roller.
2. Install the N20 gearmotor.
3. Mount the idler bearing and spring and insert m3 screws to secure position.
4. Insert the solder wire and guide tube.
5. Connect the motor, button, and power supply.
